# TorchV Unstructured 使用说明文档

## 📋 项目简介

**TorchV Unstructured** 是一个强大且开发者友好的文档解析库，专为 RAG（检索增强生成）应用优化。基于 Apache Tika、Apache POI 和 PDFBox 等业界标准 Java 库构建，提供增强的解析能力，具备智能表格结构识别和内容提取功能。

### 核心特性

- ✅ **智能表格解析**：先进的表格结构分析，支持复杂单元格合并检测
- ✅ **多格式支持**：无缝处理 DOC、DOCX、PDF 等多种文档格式
- ✅ **RAG 优化输出**：专为 AI/ML 管道设计的结构化内容提取
- ✅ **K-V 格式提取**：智能提取键值对信息，将文档信息原子化为独立语义单元
- ✅ **Markdown & HTML 导出**：灵活的输出格式，保持表格结构完整性
- ✅ **图像提取**：自动提取和处理嵌入式图像
- ✅ **内存高效**：优化的大文档处理，最小化内存占用

### 技术栈

- **Java 版本**：17+
- **核心依赖**：
  - Apache Tika 3.2.1
  - Apache POI 5.4.1
  - Hutool 5.8.26
  - Lombok 1.18.30

#### 5.5 K-V 格式在 RAG 中的应用

```java
import com.torchv.infra.unstructured.UnstructuredParser;
import com.torchv.infra.unstructured.core.KeyValuePair;
import java.util.List;

/**
 * RAG 应用中的 K-V 提取示例
 * 将文档信息原子化为独立的语义单元，便于检索和匹配
 */
public class RAGKeyValueExample {

    public static void processDocumentForRAG(String filePath) {
        // 1. 提取键值对
        List<KeyValuePair> kvPairs = UnstructuredParser.extractKeyValuePairs(filePath);

        // 2. 过滤低置信度的键值对
        List<KeyValuePair> highQualityPairs = kvPairs.stream()
            .filter(pair -> pair.getConfidence() >= 0.8)
            .toList();

        // 3. 为每个键值对生成向量并存储到向量数据库
        for (KeyValuePair pair : highQualityPairs) {
            // 构建用于向量化的文本
            String textForEmbedding = pair.getKey() + ": " + pair.getValue();

            // 生成向量（使用你的向量化模型）
            // float[] embedding = generateEmbedding(textForEmbedding);

            // 存储到向量数据库
            // vectorDB.store(embedding, pair);

            System.out.println("已处理: " + textForEmbedding);
        }
    }
}
```

**K-V 格式的优势：**

1. **信息原子化**：每条只讲一件事，避免无关信息干扰
2. **关键词明确**：Key 本身就是语义标签，容易匹配用户问题
3. **减少噪声**：不像大段文字包含冗余描述
4. **便于向量化**：每个 K-V 可作为独立 chunk 生成 embedding，提升检索精度

## 🎯 核心 API 说明

### UnstructuredParser（统一入口）

这是主要的入口类，提供简单统一的静态 API：

| 方法 | 说明 | 返回类型 |
|------|------|----------|
| `toMarkdown(String filePath)` | 解析为 Markdown 格式 | String |
| `toMarkdown(InputStream stream, String fileName)` | 从流解析为 Markdown | String |
| `toMarkdownWithHtmlTables(String filePath)` | 解析为带 HTML 表格的 Markdown | String |
| `toStructuredResult(String filePath)` | 获取完整结构化结果 | DocumentResult |
| `extractTables(String filePath)` | 仅提取表格 | List&lt;String&gt; |
| `extractKeyValuePairs(String filePath)` | 提取键值对（K-V格式） | List&lt;KeyValuePair&gt; |
| `toKeyValueMarkdown(String filePath)` | 提取键值对并转为 Markdown | String |
| `toKeyValueText(String filePath)` | 提取键值对并转为纯文本 | String |
| `toKeyValueJson(String filePath)` | 提取键值对并转为 JSON | String |
| `forKnowledgeBase(String filePath)` | 针对知识库优化的解析 | DocumentResult |
| `isSupportedFormat(String filePath)` | 检查格式是否支持 | boolean |

### DocumentResult（解析结果）

解析结果对象包含以下信息：

```java
public class DocumentResult {
    private String filePath;                  // 文件路径
    private String fileName;                  // 文件名
    private long fileSize;                    // 文件大小（字节）
    private String content;                   // 解析后的文档内容
    private List<String> tables;              // 提取的表格列表
    private List<DocumentImage> images;       // 提取的图像列表
    private List<KeyValuePair> keyValuePairs; // 提取的键值对列表（K-V格式）
    private Map<String, Object> metadata;     // 文档元数据
    private boolean success;                  // 是否解析成功
    private String errorMessage;              // 错误信息
    private long processingTimeMs;            // 处理时间（毫秒）
```

### 3. 错误处理和验证

#### 3.1 完整的错误处理

```java
import com.torchv.infra.unstructured.UnstructuredParser;
import com.torchv.infra.unstructured.util.UnstructuredUtils;

public class DocumentValidator {

    /**
     * 验证并处理文档
     */
    public ProcessingResult validateAndProcess(String filePath) {
        // 1. 检查文件格式
        if (!UnstructuredUtils.isSupportedFormat(filePath)) {
            return ProcessingResult.unsupportedFormat();
        }

        try {
            // 2. 解析文档
            String content = UnstructuredParser.toMarkdownWithHtmlTables(filePath);
            List<String> tables = UnstructuredParser.extractTables(filePath);

            // 3. 验证内容
            if (content == null || content.isEmpty()) {
                return ProcessingResult.emptyContent();
            }

            return ProcessingResult.success(content, tables);

        } catch (RuntimeException e) {
            return ProcessingResult.error(e.getMessage());
        }
    }
}

// 处理结果类
class ProcessingResult {
    private boolean success;
    private String content;
    private List<String> tables;
    private String errorMessage;

    public static ProcessingResult success(String content, List<String> tables) {
        ProcessingResult result = new ProcessingResult();
        result.success = true;
        result.content = content;
        result.tables = tables;
        return result;
    }

    public static ProcessingResult unsupportedFormat() {
        ProcessingResult result = new ProcessingResult();
        result.success = false;
        result.errorMessage = "不支持的文件格式";
        return result;
    }

    public static ProcessingResult emptyContent() {
        ProcessingResult result = new ProcessingResult();
        result.success = false;
        result.errorMessage = "文档内容为空";
        return result;
    }

    public static ProcessingResult error(String message) {
        ProcessingResult result = new ProcessingResult();
        result.success = false;
        result.errorMessage = message;
        return result;
    }
}
```

#### 错误处理策略说明

- **FAIL_FAST**：遇到错误立即抛出异常，停止处理
- **SKIP_ERRORS**：跳过错误，继续处理其他内容
- **LOG_AND_CONTINUE**：记录错误信息，返回部分结果并继续

### 4. 错误处理建议

```java
public DocumentResult safeParseDocument(String filePath) {
    try {
        // 1. 验证文件格式
        if (!UnstructuredUtils.isSupportedFormat(filePath)) {
            return DocumentResult.builder()
                    .success(false)
                    .errorMessage("不支持的文件格式")
                    .build();
        }

        // 2. 解析文档
        DocumentResult result = UnstructuredParser.toStructuredResult(filePath);

        // 3. 验证结果
        if (!result.isSuccess()) {
            System.err.println("解析失败: " + result.getErrorMessage());
        }

        return result;

    } catch (Exception e) {
        System.err.println("解析异常: " + e.getMessage());
        return DocumentResult.builder()
                .success(false)
                .errorMessage(e.getMessage())
                .build();
    }
}
```

3. **并行处理**：批量处理时使用 `parallelStream()`
4. **资源管理**：使用 try-with-resources 确保资源正确释放
5. **缓存结果**：对于重复处理的文档，考虑缓存解析结果

### 示例 1：构建知识库文档处理系统

```java
import com.torchv.infra.unstructured.UnstructuredParser;
import com.torchv.infra.unstructured.core.DocumentResult;
import com.torchv.infra.unstructured.util.UnstructuredUtils;
import java.io.File;
import java.util.ArrayList;
import java.util.List;

public class KnowledgeBaseBuilder {

    /**
     * 处理文档目录，构建知识库
     */
    public List<KnowledgeDocument> buildKnowledgeBase(String directoryPath) {
        List<KnowledgeDocument> documents = new ArrayList<>();
        File directory = new File(directoryPath);

        if (!directory.isDirectory()) {
            throw new IllegalArgumentException("路径不是目录: " + directoryPath);
        }

        // 遍历目录中的所有文件
        File[] files = directory.listFiles();
        if (files != null) {
            for (File file : files) {
                if (file.isFile() && UnstructuredUtils.isSupportedFormat(file.getAbsolutePath())) {
                    try {
                        KnowledgeDocument doc = processDocument(file.getAbsolutePath());
                        documents.add(doc);
                        System.out.println("成功处理: " + file.getName());
                    } catch (Exception e) {
                        System.err.println("处理失败: " + file.getName() + ", 错误: " + e.getMessage());
                    }
                }
            }
        }

        return documents;
    }

    /**
     * 处理单个文档
     */
    private KnowledgeDocument processDocument(String filePath) {
        // 使用针对知识库优化的解析
        DocumentResult result = UnstructuredParser.forKnowledgeBase(filePath);

        if (!result.isSuccess()) {
            throw new RuntimeException("文档解析失败: " + result.getErrorMessage());
        }

        // 创建知识库文档对象
        KnowledgeDocument doc = new KnowledgeDocument();
        doc.setFileName(result.getFileName());
        doc.setContent(result.getContent());
        doc.setTables(result.getTables());
        doc.setMetadata(result.getMetadata());
        doc.setProcessingTime(result.getProcessingTimeMs());

        return doc;
    }
}

// 知识库文档类
```

### 示例 2：表格数据提取和分析

```java
import com.torchv.infra.unstructured.UnstructuredParser;
import java.util.List;

public class TableExtractor {

    /**
     * 提取并分析文档中的所有表格
     */
    public void extractAndAnalyzeTables(String filePath) {
        // 提取所有表格
        List<String> tables = UnstructuredParser.extractTables(filePath);

        System.out.println("文档中共有 " + tables.size() + " 个表格");
        System.out.println("=".repeat(50));

        // 遍历每个表格
        for (int i = 0; i < tables.size(); i++) {
            String table = tables.get(i);

            System.out.println("\n表格 " + (i + 1) + ":");
            System.out.println("-".repeat(50));
            System.out.println(table);

            // 分析表格
            analyzeTable(table, i + 1);
        }
    }

    /**
     * 分析单个表格
     */
    private void analyzeTable(String tableHtml, int tableNumber) {
        // 统计表格信息
        int rowCount = countOccurrences(tableHtml, "<tr");
        int cellCount = countOccurrences(tableHtml, "<td") + countOccurrences(tableHtml, "<th");

        System.out.println("\n表格 " + tableNumber + " 统计信息:");
        System.out.println("  - 行数: " + rowCount);
        System.out.println("  - 单元格数: " + cellCount);

        // 检查是否有合并单元格
        boolean hasMergedCells = tableHtml.contains("colspan") || tableHtml.contains("rowspan");
        System.out.println("  - 包含合并单元格: " + (hasMergedCells ? "是" : "否"));
    }

    /**
     * 统计字符串出现次数
     */
    private int countOccurrences(String str, String substring) {
        int count = 0;
        int index = 0;
        while ((index = str.indexOf(substring, index)) != -1) {
            count++;
            index += substring.length();
        }
        return count;
    }
}
```

### 示例 3：文档对比工具

```java
import com.torchv.infra.unstructured.UnstructuredParser;
import com.torchv.infra.unstructured.core.DocumentResult;

public class DocumentComparator {

    /**
     * 对比两个文档的内容
     */
    public ComparisonResult compareDocuments(String filePath1, String filePath2) {
        // 解析两个文档
        DocumentResult doc1 = UnstructuredParser.toStructuredResult(filePath1);
        DocumentResult doc2 = UnstructuredParser.toStructuredResult(filePath2);

        if (!doc1.isSuccess() || !doc2.isSuccess()) {
            throw new RuntimeException("文档解析失败");
        }

        // 创建对比结果
        ComparisonResult result = new ComparisonResult();

        // 对比基本信息
        result.setFile1Name(doc1.getFileName());
        result.setFile2Name(doc2.getFileName());
        result.setFile1Size(doc1.getFileSize());
        result.setFile2Size(doc2.getFileSize());

        // 对比内容长度
        result.setContent1Length(doc1.getContentLength());
        result.setContent2Length(doc2.getContentLength());

        // 对比表格数量
        result.setTable1Count(doc1.getTables().size());
        result.setTable2Count(doc2.getTables().size());

        // 对比图片数量
        result.setImage1Count(doc1.getImages().size());
        result.setImage2Count(doc2.getImages().size());

        // 计算相似度（简单示例）
        double similarity = calculateSimilarity(doc1.getContent(), doc2.getContent());
        result.setSimilarity(similarity);

        return result;
    }

    /**
     * 计算内容相似度（简化版本）
     */
    private double calculateSimilarity(String content1, String content2) {
        // 这里使用简单的长度比较，实际应用中可以使用更复杂的算法
        int minLength = Math.min(content1.length(), content2.length());
        int maxLength = Math.max(content1.length(), content2.length());

        if (maxLength == 0) return 1.0;

        return (double) minLength / maxLength;
    }

    /**
     * 打印对比结果
     */
    public void printComparison(ComparisonResult result) {
        System.out.println("文档对比结果");
        System.out.println("=".repeat(60));
        System.out.println(String.format("%-30s | %-25s", "文档 1", "文档 2"));
        System.out.println("-".repeat(60));
        System.out.println(String.format("%-30s | %-25s", result.getFile1Name(), result.getFile2Name()));
        System.out.println(String.format("%-30d | %-25d 字节", result.getFile1Size(), result.getFile2Size()));
        System.out.println(String.format("%-30d | %-25d 字符", result.getContent1Length(), result.getContent2Length()));
        System.out.println(String.format("%-30d | %-25d 个表格", result.getTable1Count(), result.getTable2Count()));
        System.out.println(String.format("%-30d | %-25d 张图片", result.getImage1Count(), result.getImage2Count()));
        System.out.println("=".repeat(60));
        System.out.println(String.format("内容相似度: %.2f%%", result.getSimilarity() * 100));
    }
}

// 对比结果类
```

## ❓ 常见问题 (FAQ)

### Q1: 支持哪些文件格式？

**A:** 当前版本（v1.0.0）支持：
- Microsoft Word 文档：`.doc`, `.docx`

未来版本计划支持：PDF、PowerPoint、Excel 等格式。

### Q2: 如何处理大文件？

**A:** 对于大文件，建议：
1. 使用 `enableStreamProcessing(true)` 启用流式处理
2. 适当增加 `maxDocumentSizeInMB` 限制
3. 调整 `processingTimeoutSeconds` 超时时间
4. 使用 `highPerformance()` 配置

```java
UnstructuredConfig config = UnstructuredConfig.builder()
        .maxDocumentSizeInMB(200)
        .enableStreamProcessing(true)
        .processingTimeoutSeconds(600)
        .build();
```

### Q3: 表格解析不准确怎么办？

**A:** 尝试以下方法：
1. 确保使用 `preserveTableStructure(true)` 保持表格结构
2. 使用 `tableAsHtml(true)` 输出 HTML 格式表格
3. 检查原始文档的表格是否有复杂的嵌套或合并

```java
UnstructuredConfig config = UnstructuredConfig.builder()
        .enableTableExtraction(true)
        .tableAsHtml(true)
        .preserveTableStructure(true)
        .build();
```

### Q4: 如何提取文档中的图片？

**A:** 使用 `toStructuredResult()` 方法并启用图像提取：

```java
DocumentResult result = UnstructuredParser.toStructuredResult("document.docx");
List<DocumentImage> images = result.getImages();

for (DocumentImage image : images) {
    System.out.println("图片名称: " + image.getName());
    // 处理图片数据
}
```

### Q5: 解析失败如何调试？

**A:** 建议步骤：
1. 检查文件格式是否支持
2. 启用详细日志：`enableVerboseLogging(true)`
3. 使用 `DocumentResult` 检查错误信息
4. 尝试不同的错误处理策略

```java
DocumentResult result = UnstructuredParser.toStructuredResult("document.docx");
if (!result.isSuccess()) {
    System.err.println("错误信息: " + result.getErrorMessage());
}
```

### Q6: 如何提高批量处理性能？

**A:** 性能优化建议：
1. 使用并行流处理：`parallelStream()`
2. 使用高性能配置：`UnstructuredConfig.highPerformance()`
3. 合理设置并发线程数：`maxConcurrentThreads()`
4. 禁用不需要的功能（如图像提取）

```java
List<String> files = getFileList();
files.parallelStream()
     .forEach(file -> {
         String content = UnstructuredParser.toMarkdown(file);
         // 处理内容...
     });
```

### Q7: 支持从输入流解析吗？

**A:** 支持。可以使用带 InputStream 参数的方法：

```java
InputStream inputStream = new FileInputStream("document.docx");
String fileName = "document.docx";
String content = UnstructuredParser.toMarkdown(inputStream, fileName);
```

## 🐛 故障排除

### 问题 1: OutOfMemoryError

**症状**：处理大文档时出现内存溢出错误

**解决方案**：
1. 增加 JVM 堆内存：`java -Xmx2g -jar app.jar`
2. 启用流式处理：`enableStreamProcessing(true)`
3. 减小最大文档大小限制
4. 分批处理文档

### 问题 2: 解析超时

**症状**：处理文档时超时

**解决方案**：
1. 增加超时时间：`processingTimeoutSeconds(600)`
2. 检查文档是否损坏
3. 使用高性能配置
4. 减少并发处理数量

### 问题 3: 表格格式错乱

**症状**：提取的表格格式不正确

**解决方案**：
1. 使用 HTML 表格格式：`tableAsHtml(true)`
2. 启用表格结构保持：`preserveTableStructure(true)`
3. 检查原始文档表格是否有问题
4. 尝试使用 `extractTables()` 单独提取

### 问题 4: 不支持的文件格式

**症状**：提示文件格式不支持

**解决方案**：
1. 使用 `UnstructuredUtils.isSupportedFormat()` 检查格式
2. 确认文件扩展名正确
3. 检查文件是否损坏
4. 查看支持的格式列表
